4) أسئلة مقابلات شائعة

السؤالإجابة تظهر العمق
الفرق بين generics في C# و Java؟C# reified (النوع موجود وقت التشغيل ولا boxing للـ value types)، وJava بتمسح النوع (erasure).
إزاي الـ CLR بيتعامل مع List<int> و List<string>؟الـ value types ليها كود JIT خاص، والـ reference types بتتشارك كود واحد.
ليه ما ينفعش new T() من غير constraint؟مفيش ضمان إن T فيها constructor بدون parameters.
الفرق بين class و new()؟class يعني reference type (ممكن من غير default ctor)، وnew() بتضمن الـ constructor (وتقبل structs).
ليه List<Dog> مش List<Animal>؟لأنها invariant، لو اتسمح كان تقدر تضيف Cat.
إمتى نستخدم out و in؟out لما T بتطلع فقط (producer)، in لما بتدخل فقط (consumer).
ليه variance مش بتشتغل مع int؟التمثيل في الذاكرة مختلف (محتاج boxing)، فمش مجرد تحويل مرجع.
إيه خطر static في generic class؟نسخة لكل closed type فممكن تتخيل إنها مشتركة وهي لأ.
إزاي تتجنب boxing مع struct في generic؟constraint بـ interface مع constrained call، وIEquatable<T> للـ keys.
إيه الـ generic math؟static abstract في interfaces و INumber<T> بيسمحوا بـ + و * على T.

6) تمرين: Generic Cache بالـ Constraints والـ Variance

using System.Collections.Concurrent;

public class MemoryCache<TKey, TValue> where TKey : notnull
{
    private readonly ConcurrentDictionary<TKey, (TValue Value, DateTime Expires)> _d = new();
    private readonly TimeSpan _ttl;
    public MemoryCache(TimeSpan ttl) => _ttl = ttl;

    public TValue GetOrAdd(TKey key, Func<TKey, TValue> factory)
    {
        if (_d.TryGetValue(key, out var e) && e.Expires > DateTime.UtcNow) return e.Value;
        var v = factory(key);
        _d[key] = (v, DateTime.UtcNow + _ttl);
        return v;
    }
}

var cache = new MemoryCache<int, string>(TimeSpan.FromSeconds(30));
Console.WriteLine(cache.GetOrAdd(1, id => $"user-{id}"));   // user-1 (من الـ factory)
Console.WriteLine(cache.GetOrAdd(1, id => "other"));         // user-1 (من الـ cache)

مطلوب منك:

  1. اعمل GetOrAddAsync(TKey, Func<TKey, Task<TValue>>) وامنع تنفيذ الـ factory مرتين لنفس الـ key في نفس الوقت (فكّر في Lazy<Task<TValue>>). الكود الحالي فيه race: مين يعمل factory مرتين؟
  2. اعمل static class CacheStats<TKey,TValue> بـ Hits و Misses، واشرح ليه الأرقام منفصلة لكل تركيبة نوع.
  3. اعمل struct key (record struct OrderKey(int Id, int Tenant)) وتأكد إن الـ cache بيشتغل من غير boxing (قارن مع struct عادي من غير IEquatable).
  4. اكتب interface IReadCache<out TValue> { TValue? Get(object key); } وجرّب تضيف bool TryGet(object key, out TValue v) (هتتكسر، ليه؟ out parameter invariant).
  5. اكتب اختبار يثبت إن IReadCache<Dog> تتحول لـ IReadCache<Animal>.
  6. سجّل MemoryCache<,> كـ open generic في DI وخدها في خدمتين بتركيبات مختلفة.
